# Lab 2 - Variables and Constants

You will be writing your code in `sketch.js` within the main folder - not the `example/` folder.

To run your code open `index.html` and then click on the *Go Live* button in the bottom right.  This will open a browser page, and should refresh every time your work saves.

Re-create [this program](https://openprocessing.org/sketch/2727725/embed/?plusEmbedHash=df974a9f&userID=175929&plusEmbedTitle=true&show=sketch) using several variables for the properties that are changing (position, size, speed, etc). No constants needed - use descriptive names written in camelCase.

Once that's working, extend it:

- Add a title to the top of the screen, in a large size, that moves left to right across the screen.

- Add your name just below that, in a smaller size, that moves right to left across the screen.

- Below your name, display the value of one of your variables as text, labelled (e.g. `xValue = ____`).

- Write that same value to the console, labelled the same way.

Remember to:

- Update the header

- Include comments
